# Japanese UI font

`NotoSansJP.ttf` is the unmodified Noto Sans JP variable font, version 2.004-H2, from Google Fonts. It is used only by the Android app to keep Japanese kanji glyph forms independent of the device's default CJK fallback.

- Upstream: https://github.com/google/fonts/blob/295d98a7a0c17c68f1341eaeea354e7960ea70d3/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf
- Git blob SHA-1: `cdd8f083c1f5928ff3361f8cda4d3fc9462cbe89`

The license is also copied to `android/assets/licenses/NotoSansJP-OFL.txt` for distribution inside the APK.
